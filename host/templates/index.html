pico-bdm

background debug controller — S08/RS08

Using pico-bdm

Typical order: Connect → Sync target → Program or read/write memory. Watch the Log panel for what actually happened.

Connection
Pick your Pico's serial port (Refresh if it's missing) and click Connect. Once connected, click Sync target to measure the target chip's BDC clock — do this before any read, write, or program. Reset target is a plain RESET pulse (target reboots and runs its own code); Go resumes execution from BDM.
Flash
Set the target's bus clock in Hz and pick an erase mode: erase only the pages you're about to write (default), mass-erase the whole chip first, or skip erasing entirely. Choose a compiled .s19/.srec file and click Program. Verify after write reads each region back and confirms it matches. Run target after programming resumes the target's own code once flashing finishes. Blank check asks the FLASH module itself whether the chip is erased. The standalone Mass erase button wipes the whole chip's FLASH on its own — irreversible, used rarely.
Memory (under "Show advanced")
Read or write a single byte/block at a given address once synced — useful for peeking at registers or poking test values by hand.
Registers & breakpoint (under "Show advanced")
Read/write the CPU's A, CCR, PC, H:X and SP registers directly. Set a hardware breakpoint address (BKPT) and use Tagged GO to run until it's hit, or Step to single-step one instruction at a time. BDCSCR is the BDC's own status/control register — writing it can clear sticky flags or change the clock-switch bit.
Scope (under "Show advanced")
Self-capture diagnostic panel that draws the actual BKGD waveform without needing a separate logic analyzer. Currently disabled — it hangs the Pico and needs a hardware-level fix; see CONTEXT.md.
Options
Log display preferences (auto-scroll, timestamps) and the sample count Scope will use once it's re-enabled. Erase/verify/run-after-program options live directly in the Flash panel.
Log
Running history of every command sent and its result, newest at the bottom. Clear wipes it.
